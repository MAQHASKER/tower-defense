# Идеи после MVP

## Враги
- **Осадные враги (катапульты, вражеские баллисты):** атакуют башни с дистанции.
  Требует: Tower.hp, Tower.take_damage(), UI для починки башен за золото.
- **Летающие враги (дирижабли):** игнорируют путь, летят напрямую к ратуше.
  Не блокируются казармами. Требует: Enemy.movement_mode (path/fly),
  Tower.can_target_air, противовоздушные башни.
- **Боссы:** огромные враги с уникальными способностями. На 10-й, 20-й волне.
- **Вражеские герои:** сильные юниты с аурами, способностями.

## Союзники
- **Союзный генерал:** герой, стоит на карте, бьёт врагов, имеет способности.
  Требует: класс Unit, способности, апгрейды героя.
- **Союзная армия:** отряд, спавнится, идёт навстречу врагам, сражается.
  Переиспользует код Enemy.gd (только цели — враги).

## Режимы игры
- **«Колодец»:** режим героев между этапами. Управление персонажем,
  встреча с врагами следующих волн. Отдельная камера, отдельный UI.
- **Типы этапов:** не только N волн, но и «выживи N минут», «убей босса».
  Требует: Objective с типами.

## Мета-прогрессия
- Дерево улучшений между этапами.
- Открытие новых башен.
- Прокачка генерала.
- Сохранение: campaign.json расширяется.

## Мир
- Разные фракции (люди, эльфы, орки, нежить).
- Погода (дождь, снег, туман) — влияет на видимость, скорость.
- День/ночь — влияет на врагов (нежить сильнее ночью).
- Разные биомы: лес, пустыня, горы, болото.

## Геймплей
- Перемещаемая точка сбора казарм (клик по карте).
- Разрушаемые башни (осадные враги).
- Починка башен за золото.
- Масштабные апгрейды (ветки развития башен).
- Способности игрока (молния, заморозка, лечение) с кулдауном.
- Дерево технологий.

## Визуал и звук
- Анимации врагов (idle, walk, attack, die).
- Анимации башен (выстрел, поворот).
- Эффекты: взрывы, попадания, всплывающие цифры урона.
- Частицы: кровь, искры, дым.
- Музыка: спокойная в паузах, напряжённая в волнах.
- Звуки: выстрелы, удары, смерть, постройка.

## Техническое
- Пул объектов для снарядов и врагов.
- Сохранение между волнами (mid-game save).
- Оптимизация для 100+ юнитов.
- Локализация (русский, английский).
- Мультиплеер (очень потом, отдельный проект по сложности).

## Срочно (техническое)
- **Стартовое золото 2000 → 200** перед релизом
- **Переделать управление камерой** с `ui_*` на `camera_*` — сейчас WASD конфликтует с UI-навигацией
- **Мерцание врага** — не помогло поднятие на 0.7. Проверить: shadow acne (Bias в DirectionalLight), path-плитки (y=0.06), настройки теней

## Визуал башен
- При апгрейде менять модель, а не масштабировать куб.
- Уровень 1/2/3 — разные модели (дерево → укреплённая → камень/магия).
- В Blender: три отдельные модели или модульная сборка.
