# Архитектура проекта

Что где лежит и что какой файл делает. Читать при возврате к коду.

## Слои физики

| Слой | Бит | Кто |
|---|---|---|
| 1 (default) | 0 | земля (`StaticBody3D` для raycast-постройки) |
| 2 | 1 | враги (`Enemy`) — сталкиваются только друг с другом |
| 4 | 2 | постройки (`Barracks`) — солдаты о них опираются |
| 8 | 3 | солдаты (`Soldier`) — сталкиваются только с постройками |

## Группы

- `"enemies"` — все враги
- `"soldiers"` — все воины казарм
- `"barracks"` — все казармы

## Сцены (`scenes/`)

| Сцена | Что |
|---|---|
| `MainMenu.tscn` | главное меню: Начать игру / Настройки (заглушка) / Выход |
| `StageSelect.tscn` | выбор этапа, список из `stages.json` |
| `Main.tscn` | игровой уровень: Ground, Entities, WaveSpawner, Camera, HUD, BuildPanel, TowerPanel, EndScreen, Sun, Environment |
| `ui/HUD.tscn` | верхняя панель (золото/волна/HP) |
| `ui/BuildPanel.tscn` | нижняя панель (кнопки башен + «Начать волну») |
| `ui/TowerPanel.tscn` | панель выбранной башни (улучшить/продать) |
| `ui/EndScreen.tscn` | экран победы/поражения |

## Автолоады (`project.godot`)

- `GameManager` — золото, HP ратуши, номер волны, `selected_stage`, сигналы.
  Единственный источник правды о состоянии партии.
- `McpInteractionServer` — служебный скрипт godot-bridge. Не трогать.

## Глобальные классы (`scripts/`)

| Файл | Что |
|---|---|
| `Constants.gd` | клетка 3 м, карта 24×24, цвета, `cell_to_world()`, `map_center()`, `USE_MODELS`, `EARLY_START_COOLDOWN` |
| `Path.gd` | путь: ломаная из углов → список клеток (`from_corners`, `expand`) |
| `Grid.gd` | занятость клеток (`occupy` / `is_free` / `release` / `mark_path` / `mark_base`) |
| `StageLoader.gd` | чтение `stages.json` (этапы, волны, путь). Подключается через `preload` |

## Управление уровнем

| Файл | Что |
|---|---|
| `Main.gd` | корень уровня: строит землю/путь/ратушу, постройка башен через raycast, читает выбранный этап |
| `WaveSpawner.gd` | волны: пачки, спавн-зона, кулдаун досрочного старта |
| `CameraController.gd` | камера: WASD, зум, поворот Q/E, пивот зажат в границах карты |

## Юниты (`scripts/units/`)

| Файл | Что |
|---|---|
| `Enemy.gd` | `CharacterBody3D`. Идёт по пути, коллизии с другими врагами, слоты в клетке, `claimed_by` (какой солдат его ведёт), `trample`, `can_be_blocked` |
| `Soldier.gd` | `CharacterBody3D`. Бой / возврат домой, «один враг — один солдат», обход построек (`_avoid`), мягкое расталкивание (`_separation`) |
| `Projectile.gd` | самонаводящийся снаряд |

## Здания (`scripts/buildings/`)

| Файл | Что |
|---|---|
| `Tower.gd` | лучник (`.glb` с автоподгонкой под клетку) / баллиста / заглушка; стрельба, апгрейд, продажа |
| `Barracks.gd` | `StaticBody3D`. Точка сбора на ближайшей свободной клетке пути, спавн/респавн солдат, апгрейд |
| `Base.gd` | ратуша 3×3 клетки в конце пути |

## UI (`scripts/ui/`)

| Файл | Что |
|---|---|
| `HUD.gd` | золото/волна/HP, подписка на сигналы GameManager |
| `BuildPanel.gd` | кнопки башен + «Начать волну» с кулдауном и отсчётом |
| `TowerPanel.gd` | улучшить/продать выбранную башню |
| `EndScreen.gd` | победа/поражение, «Заново», «В меню» |
| `MainMenu.gd`, `StageSelect.gd` | меню и выбор этапа |

## Данные (`data/`)

| Файл | Что |
|---|---|
| `balance.json` | враги: hp, speed, damage, width/depth/height, slot_cols/slot_rows, trample, can_be_blocked, color, model. Башни: cost, damage, range_cells, cooldown, color |
| `stages.json` | этапы: `path` (ломаная из угловых точек), `waves` (список пачек) |

## Ключевые договорённости

- **Габариты — только в `balance.json`.** Модель подгоняется к ним (`Enemy._fit_visual`, `Tower._fit_model_to_cell`).
- **Модели выключены** — `Constants.USE_MODELS = false`. Включить = одна строка.
- **Скорость врага** — в клетках/сек. Движение привязано к фактически пройденному пути, поэтому застрявший враг не «набирает» путь.
- **UI ↔ GameManager через сигналы** — UI не трогает логику напрямую.
- **Путь и этапы — только в `stages.json`**, код не трогать. Новый этап подхватывается меню автоматически.
- **Настройки в `Constants.gd`** — единая точка для чисел, которые нужны нескольким файлам.
